# ParSe_v2_training_sets
Sequence sets used to define folded regions, phase-separating (PS) IDRs, conventional (non-PS) IDRs, and high-pathogenicity PS-IDRs.

These files are a curated compilation. The underlying sequences come from public resources such as UniProt, and users should follow those original terms. This compilation is available under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). 

Please cite Ibrahim et al., J. Biol. Chem. 299, 102801 (2023), and Remo et al. (citation to be updated on publication).
